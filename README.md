# Customer Support Analytics Dashboard

## Project Overview
This project focuses on analyzing customer support call data and presenting key business insights through a dashboard created using WPS Spreadsheet.

## Tools & Techniques
- WPS Spreadsheet
- Pivot Tables
- Pivot Charts
- VLOOKUP
- Data Analysis
- Data Visualization

## Key Performance Indicators (KPIs)
- Total Calls
- Total Amount
- Total Duration
- Average Customer Rating

## Dashboard Features
1. Monthly Call Trend
2. Calls by Representative
3. Customer Satisfaction Analysis
4. Calls & Purchase Amount by Representative
5. Gender-wise Calls by City

## Objective
To analyze customer support performance, understand customer satisfaction, and visualize important business metrics.

## Dataset
The project uses a sample customer support call dataset. Credit goes to the original dataset creator.
